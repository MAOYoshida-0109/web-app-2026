# API仕様

## GET /api/tasks
説明：タスク一覧を取得する

レスポンス：
{
  "id": 1,
  "title": "レポート提出",
  "completed": false
}

サーバー・フロントエンドでの使われ方：
フロントエンドはページを開いたときに、サーバーへGETリクエストを送る。
サーバーは保存されているタスク一覧を返し、画面に表示する。

---

## POST /api/tasks
説明：新しいタスクを追加する

リクエスト：
{
  "title": "レポート提出"
}

レスポンス：
{
  "id": 1,
  "title": "レポート提出",
  "completed": false
}

サーバー・フロントエンドでの使われ方：
フロントエンドは入力フォームに書かれたタスク名をサーバーへ送信する。
サーバーは新しいタスクを保存し、追加後のデータを返す。

---

## PATCH /api/tasks/1
説明：タスクの状態（チェック有無）を更新する

リクエスト：
{
  "completed": true
}

レスポンス：
{
  "id": 1,
  "title": "レポート提出",
  "completed": true
}

サーバー・フロントエンドでの使われ方：
フロントエンドはチェックボックスが押されたときに、変更内容をサーバーへ送信する。
サーバーは対象タスクの状態を更新し、更新後のデータを返す。

---

## DELETE /api/tasks/1
説明：タスクを削除する

レスポンス：
{
  "message": "タスクを削除しました"
}

サーバー・フロントエンドでの使われ方：
フロントエンドは削除ボタンが押されたときに、サーバーへDELETEリクエストを送る。
サーバーは対象タスクを削除し、削除完了メッセージを返す。
